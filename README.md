# Neoteseo Mayorista - Catálogo

Archivos listos para GitHub Pages.

## Cómo publicarlo
1. Entrá al repositorio: https://github.com/neoteseostore-tech/catalogo
2. Subí `index.html` y `productos.json` a la raíz del repositorio.
3. Entrá a Settings > Pages.
4. En Source elegí: Deploy from a branch.
5. Branch: main / root.
6. Guardá.

El link debería quedar:
https://neoteseostore-tech.github.io/catalogo/

Nota: las imágenes se cargan desde Extrashop por URL. Si querés que funcione 100% offline, después hay que descargar esas imágenes y subirlas a una carpeta /images.
